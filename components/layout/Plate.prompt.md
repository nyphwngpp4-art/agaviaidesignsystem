# Plate

A bordered "diagram plate" with L-shaped corner ticks and two monospace meta labels along the top edge — frames a diagram or figure so it reads like a technical drawing. Fill is bone-2.

```jsx
<Plate metaLeft="◇ Plate · The Engine · Five phases" metaRight="Diagram 02 · v1.4">
  <svg viewBox="0 0 1240 440" style={{ width: "100%", display: "block" }}>…</svg>
</Plate>
```

Best for the engine timeline, org diagrams, or any SVG figure. Keep the meta labels short and monospace.
