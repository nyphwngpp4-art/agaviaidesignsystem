# FounderQuote

A pull quote set off by a left agave rule on a bone-2 fill — serif italic, light weight. Use for the founder's voice or any highlighted statement.

```jsx
<FounderQuote cite="— Owner, Agavi AI">
  We don't sell software. We architect transformation.
</FounderQuote>
```

`cite` renders as a small monospace attribution below the quote.
