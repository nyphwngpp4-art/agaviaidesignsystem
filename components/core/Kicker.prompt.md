# Kicker

The monospace eyebrow that opens an Agavi section — uppercase, wide letter-spacing, ink-mute, with a terracotta ◇ diamond in front.

```jsx
<Kicker>The methodology · Our moat</Kicker>
<Kicker diamond={false}>Pricing</Kicker>
```

Pair it above a serif `<h2>`. Use `·` (middle dot) to separate phrases. Set `diamond={false}` to drop the ◇.
