# Tag

An outlined monospace pill for capability chips — bordered (not filled), uppercase, ink-mute. Lay several in a flex row with `gap: 8px`.

```jsx
<div style={{ display: "flex", gap: 8, flexWrap: "wrap" }}>
  <Tag>CRM Intelligence</Tag>
  <Tag>Operations</Tag>
  <Tag>Sales Enablement</Tag>
</div>
```
