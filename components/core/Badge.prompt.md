# Badge

A small filled marker that flags a featured item — terracotta fill, bone text, monospace uppercase. On a `Tier` card it's positioned absolutely at the top-left notch.

```jsx
<Badge>Most Chosen</Badge>
<Badge tone="agave">New</Badge>
```

Tones: `terracotta` (default), `agave`, `ink`. Keep the label 1–2 words.
