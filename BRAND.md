# Agavi AI — Brand Brief for AI Agents

Read this file first before producing any Agavi asset (posts, graphics, emails, docs, slides, web pages). Follow it exactly. For depth, see `readme.md` and `guidelines/`.

## Who we are
Agavi AI is a boutique AI consultancy for founder-led service businesses in the East Valley, Arizona. Tagline: "Operational intelligence, installed." Voice: editorial, plainspoken, confident, consultant-grade. No hype, no buzzwords, no emoji.

## Color (use only these)
- Bone `#f3eee4`: default background (paper)
- Ink `#1a1f1a`: primary text, dark buttons
- Ink soft `#2c332b`: body text
- Agave deep `#1f3a32`: brand green, dark surfaces, rules
- Terracotta `#b8552d`: single accent (the period, ◇ marks, links). Use sparingly.
- Muted `#6a6f64`: labels, captions
- Hairline `#d4d1c8`: 1px dividers

Never: pure white, pure black, blue, gradients, neon, drop shadows.

## Type (Google Fonts only)
- **Newsreader** (serif): headlines, display, ledes. Italic for emphasis.
- **Inter Tight** (sans): body copy and UI.
- **JetBrains Mono**: small UPPERCASE labels and kickers, wide letter-spacing.
No other typefaces.

## Logo / wordmark
There is no image logo. Set **Agavi.** in Newsreader (medium weight) in ink or bone, with the period in terracotta `#b8552d`. Optional line motif: `assets/agave-motif.svg`.

## Motifs
- Terracotta period after the wordmark
- ◇ diamond as list marker and section kicker
- Hairline (1px) rules and divided grid cells
- Square corners on surfaces; pill-shaped buttons
- Generous whitespace, editorial layouts, numbered sections (01, 02…)

## Writing rules
- Short, concrete sentences. State the point in the headline.
- No em-dashes in client-facing documents or emails (marketing headlines only).
- Never invent statistics, testimonials, logos or credentials.

## Don'ts
No stock photos, emoji, gradient backgrounds, rounded card grids, pill badges everywhere, KPI tiles, or decorative icons standing in for content.

## Files

- `assets/` → motif and icons
- `guidelines/` → detailed usage
- `templates/` → reusable starting files (email stationery, invoice)
