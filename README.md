# Agavi AI — Design System

Canonical brand system for Agavi AI. Exported from Claude Design on 2026-08-27 (project: Agavi brand download package).

Editorial bone-and-ink identity: warm bone stock, near-black ink, deep agave green, one terracotta accent. Type: Newsreader (display), Inter Tight (body/UI), JetBrains Mono (labels).

Consumers link `styles.css`.

Do not invent a visual identity. If a screen disagrees with these tokens, the tokens win.
